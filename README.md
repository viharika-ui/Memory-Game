# 🧠 Memory Game

A fun, interactive **Memory Card Game** built using **HTML, CSS, and JavaScript**.  
Test your brain by matching emoji pairs across multiple difficulty levels!

---

## 🎮 Game Features

- 🟢 **Three difficulty levels**  
  - Easy  
  - Medium  
  - Hard  

- ⏱️ **Live Timer**
- 🔢 **Move Counter**
- ⏸️ **Pause & Resume**
- 🔄 **Restart Game**
- 🏆 **Best Time Saved** (using LocalStorage)
- 🎉 **Win Popup with Stats**
- 📱 **Responsive Design**

---

## 🧠 How to Play

1. Select a difficulty level.
2. Click two cards to flip them.
3. If both match → they stay open.
4. If not → they flip back.
5. Match all pairs to win!

Try to finish in **minimum time and moves**.
